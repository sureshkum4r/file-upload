How to Use this website to upload your files

Create an account in cloudinary

👉 Click here to create account

Find your cloud name

Make sure to note it somewhere to use it for uploading files.

  1. Click on Home button.
  2. You will find cloud name here.

Create upload preset

Create your upload preset. Make sure to note it too.

  1. Click on Setting button.
  2. Cick on Upload.
  3. Click on Add Upload Preset button.

Setup upload preset

Be careful here.

  1. You can use any name, make sure it is not starting with symbol or number to make simple enough to remember.
  2. Important part! Make sure it is set to 'unsigned', otherwise this will not work.
  3. (optional) You can set a folder where all your files will be uploaded.
  4. Enable this option, so that it will use the file name you have given not random generated text.

You are all set up!

You can use the website to upload your files.

  1. Remember your cloud name and upload preset
  2. Enter the respective value in the input field in the website.
  3. Click Upload button a dialog will appear.
  4. Click browse, select your files and click on open (or) drag and drop your files on the dialog.
  5. Click done and your files are uploaded.

How to access your files

This is like google drive. Login to Cloudinary here

  1. If you can't find your file, click on Assets Button
  2. Click on Assets.

Now you can select and download your files delete it if you want to.
